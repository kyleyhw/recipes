# Source Serif 4

The two `.woff2` files in this directory are subsets of **Source Serif 4**,
designed by Frank Grießhammer for Adobe.

- Copyright 2014–2023 Adobe (https://adobe.com/), with Reserved Font Name
  "Source".
- Licensed under the **SIL Open Font License, Version 1.1**.
- Upstream: https://github.com/adobe-fonts/source-serif

The OFL permits redistribution — including bundled inside a website, which is
what this repository does — provided the licence travels with the font. **Copy
`OFL.txt` from the upstream release into this directory** if it is not already
here; that file is the licence, and this note is not a substitute for it.

The font is self-hosted rather than loaded from a CDN so that nothing on the
page is fetched from a third party: the site is static, and a font on someone
else's server would be the only thing on it that could fail, be slow, or watch
the reader.
